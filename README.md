# HOI4 Parsed Save Animation Repo

This repo is the parsed-data version of the HOI4 game log archive.

## What changed
- built for parsed save data only
- animation uses state owner data to colour states
- keeps the same site style / homepage format
- each game lives in its own folder under `games/`

## Add a new game
1. Drop the generated game folder into `games/`
2. Add one entry to `games/games.json`
3. Push to GitHub Pages
